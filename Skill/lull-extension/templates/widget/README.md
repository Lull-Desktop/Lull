# __NAME__ (tool extension)

Lull third-party widget skeleton, generated by the `lull-extension` skill.

```text
__DIR__/
  widget.json       # manifest: schemaVersion 2, id = __ID__
  index.html        # entry
  main.js           # logic (imports ./vendor/widget-sdk/index.js)
  style.css
  vendor/           # copy of the SDK dist, native ESM, no bundler needed
```

## Development

```bash
lull-ext vendor .                       # re-sync the SDK after building it
lull-ext validate .                     # standard check (manifest + artefacts + sandbox rules)
lull-ext pack . --out ./artifacts       # produce .lull-widget.zip
```

Install: Lull -> Settings -> Extensions -> Install from file and pick the zip; or turn on
"Developer mode" at the bottom of the Extensions page and mount this directory directly.
Once installed, edit `main.js` and hit "Reload" on the card (no repack needed).

## Hard constraints

- The iframe is an opaque origin: **no** localStorage / cookie / host DOM / Tauri IPC;
- Keep state in `client.getState` / `setState` (one value <= 32 KiB, 256 KiB per plugin);
- No inline `onclick=` handlers, no root-absolute `/assets/...` paths;
- Network access must be declared in `widget.json` `network` as an `https://` origin and
  comes with the `widget.network` capability;
- Do not set `color-scheme: dark` on `:root` inside a transparent window.
