# __NAME__ (wallpaper scene)

Lull content package skeleton, generated by the `lull-extension` skill.

```text
__DIR__/
  catalog.json                  # schemaVersion 1, exactly one scene (id = __SCENE_ID__)
  scenes/__SLUG__/
    index.html                  # entry (must live inside a subdirectory)
    main.js                     # script scenes only: imports ./vendor/scene-sdk/index.js
    vendor/                     # script scenes only: SDK copy (must sit next to the entry so the digest covers it)
```

## Development

```bash
lull-ext vendor .                        # script scenes: sync scene-sdk
lull-ext hash .                          # every content change needs a fresh integrity
lull-ext validate .                      # standard check
lull-ext pack . --out ./artifacts        # produce <id>-<version>.zip
```

Install: Lull -> Settings -> Extensions -> Install from file, then pick the scene on the
Wallpaper page. Installing the same id again **overwrites** the old version; there is no
rollback, so verify in developer mode before publishing.

## Digest rules

`integrity` covers the **entry directory** (`scenes/__SLUG__/**`) and excludes
`catalog.json`. Any change to `main.js` or an asset requires `lull-ext hash .`, otherwise
the installer rejects the package on a digest mismatch.
