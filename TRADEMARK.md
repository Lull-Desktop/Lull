## Forks

If you distribute a modified version, please:

1. choose a different product name;
2. replace the application icon and splash branding;
3. keep the source and license notices intact;
4. make it clear that the fork is not endorsed by the Lull project.

Questions about trademark use can be raised in the repository issue tracker.
