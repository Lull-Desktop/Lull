# Lull 使用指南

[项目首页](../../README.zh-CN.md) · [开发参考](development.zh-CN.md)

本文描述当前源码对应的操作。安装包的功能范围请同时参考对应 Release 说明。

## 安装与首次使用

1. 从 [GitHub Releases](https://github.com/Lull-Desktop/Lull/releases/latest) 下载 Windows x64 安装包或便携版。
2. 在 Windows 10 / 11 上安装或解压运行；确保 WebView2 Runtime 可用，Explorer 桌面正常运行。安装包目前未签名，可能出现未知发布者提示。
3. 从系统托盘打开设置，在“壁纸”页选择场景、开启“显示壁纸”，按需设置显示器模式。
4. 从托盘打开音乐播放器或音境控制器；需要退出时使用托盘的“退出”。

本地壁纸、曲库、音境与已安装扩展无需账号。离线运行需要素材及运行时已经在本机就绪。

## 托盘与窗口

左键点击托盘图标显示或隐藏设置，右键打开菜单。关闭设置和资料库窗口只会隐藏窗口，不代表退出应用。壁纸窗口位于桌面图标下，不进入任务栏。

| 入口 | 用途 |
| --- | --- |
| 显示 / 隐藏设置 | 切换设置窗口 |
| 音乐播放器 / 音境 | 打开当前功能槽位选中的实现 |
| 扩展 | 打开已启用的工具扩展；没有可用项时不显示 |
| 设置下的管理入口 | 打开壁纸、音乐、音境管理窗口 |
| 退出 | 停止应用并卸下桌面壁纸 |

同一功能槽位选择一个实现；第三方播放器不会因为安装成功就自动替换当前播放器。

## 设置页

| 页签 | 主要操作 |
| --- | --- |
| 偏好 | 界面语言、主题、任务栏与窗口行为 |
| 壁纸 | 总开关、多屏模式、同步、场景选择、参数和壁纸管理入口 |
| 音乐 | 全部歌曲、收藏、队列、歌单、最近添加和最近播放；音乐管理入口与播放器实现选择 |
| 音境 | 当前混音轨道、播放与音量、睡眠定时器、预设应用，以及音境管理入口与实现选择 |
| 游戏 | 已安装游戏的实例状态、启动 / 停止、保存、存档及控制器操作 |
| 扩展 | 安装、启用 / 停用、打开、更新、卸载，以及功能槽位选择 |
| 关于 | 应用版本、项目介绍与相关信息 |

## 壁纸与多屏

| 模式 | 效果 |
| --- | --- |
| 复制 | 每台显示器显示相同场景，可开关动画同步 |
| 独立 | 每台显示器分别选择和设置壁纸 |
| 跨屏 | 多台显示器共享画布，按物理像素桌面坐标裁剪，同步固定开启 |

场景能否提供参数、鼠标响应、音频响应或同步，取决于其清单声明与宿主兼容性。音频响应读取 Lull 自身音频引擎的数据，不采集其他应用的系统音频。

图片和视频从本地选择，视频默认使用 HTML 播放。本地视频登记路径，不复制大文件；移动或删除原文件后需要重新选择。原生共享解码是另行构建的可选能力，见[媒体运行时](../media-runtime.md)。

着色器壁纸支持粘贴 GLSL 或载入 `.glsl` / `.frag` 文件；参数和编译问题见[着色器指南](../shadertoy-import.md)。

## 音乐与音境

在音乐管理窗口添加本地目录并扫描，再从设置页浏览歌曲、收藏、队列与歌单。目录管理、标签和智能歌单等管理功能位于音乐管理窗口。播放器通过共享媒体服务操作播放状态；切换界面实现不需要重新建立一套曲库。

音境可组合多条轨道并分别调整音量，内置声音只是起点。通过音境管理窗口维护本地素材、分类、标签和预设，再在设置页应用预设。睡前播放可设置睡眠定时器；需要保留一套搭配时，将当前混音保存为预设。

## 安装、更新与切换扩展

1. 打开“设置 → 扩展”，选择“从文件安装”，或拖入支持的扩展包。
2. 阅读导入摘要中的名称、版本、能力与体积，再确认安装。
3. 第三方扩展安装后还需启用并授予声明的能力，才能运行。
4. 普通工具从扩展列表或托盘打开；播放器、音境控制器需要在“功能槽位”选择当前实现。
5. 更新同一 ID 的扩展需要更高的语义版本，相同版本和降级会被拒绝。更新失败会尝试恢复旧包；恢复失败时按错误提示处理，不能把这一机制当作无条件恢复保证。
6. 卸载使用二次确认；按界面提示在确认时限内再次点击。

目前使用本地包分发，没有在线扩展市场或自动更新服务。目录挂载与热调试面向作者，见[扩展开发模式](../extension-dev-mode.md)。

### 安装番茄钟或 Mini Player 示例

番茄钟不随安装包启用。开发者可在已准备依赖的仓库根目录运行：

```powershell
pnpm widgets:samples:build
pnpm widgets:samples:install
```

然后在扩展中心启用“番茄钟（Liquid）”。它提供专注、短休、长休三段轮换，偏好会保存。安装脚本直接写入当前用户的扩展目录；也可使用[开发参考](development.zh-CN.md)中的打包命令，通过界面安装 ZIP。

只体验替换播放器的示例：

```powershell
pnpm widgets:samples:build mini-player
pnpm widgets:samples:install mini-player
```

启用 **Mini Player (Example)**，在“功能槽位 → 音乐播放器”中切换实现。

## 配置、日志与反馈

| 内容 | 位置 |
| --- | --- |
| 显示与窗口配置 | `%APPDATA%\app.lull.desktop\display.json` |
| 应用日志 | `%TEMP%\lull\app.log` |
| 原生宿主日志 | `%TEMP%\lull_wallpaper.log` |
| 桌面验收截图与日志 | `%TEMP%\lull\` |

反馈时附 Lull 版本、Windows 版本、复现步骤和相关日志。壁纸挂载问题还需说明显示器数量、排列、分辨率和缩放比例。普通问题使用 [Issues](https://github.com/Lull-Desktop/Lull/issues)，安全问题按 [SECURITY.md](../../SECURITY.md) 私密报告。
